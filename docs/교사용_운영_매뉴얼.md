# WORLD 2050 교사용 운영 매뉴얼

## 1. 수업 전 준비 (10분)

1. `접속주소/teacher`에 들어가 관리자 비밀번호로 로그인합니다.
2. **새 게임방 만들기**: 학급 이름과 라운드당 시간을 정합니다. 학급마다 방을 하나씩 만듭니다.
   - 50분 수업: 라운드당 6~8분 / 100분(2차시): 라운드당 12~15분 권장
3. **관리 화면 열기 → 입장 안내와 참가자**에서 방 코드와 6개 국가 참가 코드를 확인합니다. 국가 코드는 해당 모둠에만 알려 줍니다(쪽지나 모둠 카드 추천).
4. 전자칠판에서 **전자칠판 화면 열기**를 눌러 세계 현황판을 띄우고 "전체 화면"을 누릅니다.
5. 학급을 6개 모둠(3~6명)으로 나눕니다.

## 2. 수업 진행 순서

| 단계 | 교사가 할 일 | 학생 활동 |
| --- | --- | --- |
| 입장 (5분) | 칠판에 접속 주소와 방 코드 안내 | 방 코드·국가 코드·닉네임 입력. 가장 먼저 들어온 학생이 대표 |
| 안내 (3분) | 목표 설명: "모든 나라가 살아남고 평화 지수 65 이상이면 다 함께 승리" | 대기실 안내문, 국가 프로필 읽기 |
| ROUND 1~5 | **게임 시작** → 시간 종료 시 자동 결산 → 결과 짚어 주기 → **다음 라운드 시작** | ① 부족한 자원 거래 ② 정책 카드 1장 ③ 사건 카드 응답, 퀴즈 |
| 마무리 (10분) | 결과 화면으로 토의 진행, 성찰 작성 안내 | "보고서" 탭에서 성찰 작성 후 PDF 저장 |

### 화면 위쪽 조작 버튼

- **일시정지 / 재개**: 전체 안내가 필요할 때. 정지 중에는 학생의 모든 행동이 잠깁니다.
- **+1분 / −1분**: 진행 중인 라운드의 시간 조절.
- **라운드 종료·결산**: 시간이 남았어도 바로 결산합니다.
- 시간이 다 되면 서버가 자동으로 결산하며, 그 뒤에 도착한 행동은 받지 않습니다.

### 라운드별 진행 요점

1. **물 부족 위기** — 첫 화면의 "이번 라운드 할 일" 세 가지를 함께 읽고, 붉은 자원 카드의 **요청하기** 버튼으로 첫 거래를 해 보게 합니다. 「국제 물 협력 기금」은 4개국 이상 참여해야 성공합니다.
2. **에너지 위기** — 솔라니아에 협상이 몰립니다. "자원을 무기로 쓰면 신뢰는?" 질문을 던져 보세요.
3. **수자원 분쟁** — 그린벨트·솔라니아는 입장을 비공개로 확정하고, 나머지 4개국은 중재에 나설 수 있습니다(무료). 결과는 라운드가 끝날 때 공개됩니다.
4. **기후 재난** — 오세아나·노바리아가 피해를 입습니다. 그동안의 세계 환경 지수에 따라 피해 규모가 달라집니다. 나머지 4개국 중 3개국 이상이 「국제 재난 구호」에 참여하면 성공합니다.
5. **세계 평화 정상회의** — 조항 5개에 찬성·반대로 투표합니다. 4개국 이상 찬성한 조항이 3개 이상이면 채택되고, 효과는 찬성한 나라에 적용됩니다. 전체 회의 형식으로 진행하면 좋습니다.

## 3. 탭별 기능

- **국가 현황**: 6개국의 자원·지표·정책 카드 선택 여부·부족 예상·대표 접속 여부를 실시간으로 봅니다.
- **거래·약속**: 모든 거래 제안과 함께 맺은 약속.
- **활동 기록**: 시간순 전체 기록(국가별 필터).
- **국제 사건**: 감염병, 풍년 등 돌발 사건을 직접 발동합니다. 협상이 느슨해질 때 활용하세요.
- **복구·설정**: 라운드 시간 변경, 라운드 시작 시점으로 되돌리기, 수동 조정, 게임 초기화.
- **결과·보고서**: 결과 확인, CSV(엑셀)·JSON 내려받기, 6개국 보고서 인쇄/PDF 저장.
- 게임방 목록 화면 아래 **학급별 결과 비교** 표에서 여러 학급의 결과를 나란히 볼 수 있습니다.

## 4. 문제가 생겼을 때

| 상황 | 해결 |
| --- | --- |
| 학생 화면에 "재연결 중" | 자동으로 다시 연결됩니다. 안 되면 새로고침. 게임 상태는 서버에 있어 사라지지 않습니다. |
| 학생이 기기를 바꿈 / 브라우저 기록 삭제 | 같은 방 코드·국가 코드로 다시 입장시킨 뒤, 필요하면 "대표 지정"을 누릅니다. 예전 접속은 ✕로 내보냅니다. |
| 대표가 자리를 비움 | 입장 안내에서 다른 학생 옆 **대표 지정**. (대표가 접속 중이 아니면 같은 모둠 학생이 직접 "대표 권한 받기"도 가능) |
| 잘못된 국가로 입장 | ✕로 내보낸 뒤 올바른 코드로 다시 입장 |
| 실수로 라운드를 넘김 / 큰 오류 | 복구·설정 → **ROUND n 시작으로** 되돌리기 (일시정지 상태로 복구되며 "재개"를 누르면 진행) |
| 자원 수치를 바로잡아야 함 | 복구·설정 → 수동 조정 (기록에 남음) |
| 서버가 재시작됨 | 저장된 상태에서 자동으로 이어집니다. 진행 중이던 라운드의 타이머는 그대로 흐르므로 필요하면 +1분으로 보정하고, 그사이 시간이 다 지나 결산되었다면 "라운드 시작으로 되돌리기"를 쓰세요. |
| 처음부터 다시 | 복구·설정 → 게임 초기화 (참가자는 유지) |

## 5. 평가와 토의 안내

- 국가 점수는 순위를 매기기 위한 것이 아니라 **균형**(생존·행복·환경·신뢰·기여)을 보기 위한 것입니다.
- 공동 승리에 실패한 경우가 오히려 좋은 토의 자료가 됩니다: "어느 라운드에서, 어떤 선택이 달랐다면?"
- 점수와 지수는 학습용 지표이며 실제 국제사회를 정확히 수치화한 것이 아님을 학생들에게 알려 주세요.
- 지식 카드의 내용은 실제 사실에 바탕을 두었고, 국가와 사건은 모두 가상입니다.

### 토의 질문 예시

1. 우리 나라의 이익과 세계의 이익이 부딪친 순간은 언제였나요? 어떻게 결정했나요?
2. 가장 신뢰가 갔던 나라는 어디였고, 그 이유는 무엇인가요?
3. 노바리아와 오세아나는 왜 스스로의 힘만으로 위기를 넘기 어려웠을까요?
4. 실제 세계에서 오늘 게임과 비슷한 일은 무엇이 있을까요?

## 6. 수업 전 점검표

- [ ] 교실 와이파이에서 학생 기기 몇 대로 미리 접속해 보았다
- [ ] 학급 게임방을 만들고 국가 코드를 모둠별로 준비했다
- [ ] 전자칠판에 세계 현황판을 띄웠다
- [ ] 라운드 시간을 수업 시간에 맞게 정했다
- [ ] 지난 수업의 결과를 보관해야 한다면 CSV/PDF로 내려받았다
